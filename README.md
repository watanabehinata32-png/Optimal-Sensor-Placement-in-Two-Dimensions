# 量子アニーリングによるセンサー配置最適化

8つの市町村に3種類のセンサーをどう置けば、**各市町村の必要条件を満たしつつ総コストを最小にできるか**を、
量子アニーリング（Fixstars Amplify AE）で解く Streamlit アプリです。

**公開URL：https://optimal-sensor-placement-in-two.onrender.com/**
（無料プランのため、しばらく使われていないと最初の表示に1分ほどかかります）

## 使い方

1. 必要ならタブでセンサーの性能や市町村の必要値を編集する
2. 「QUBOを実行」を押す
3. 総コスト・設置台数・条件を満たした市町村の数と、配置の地図、市町村ごとの達成状況が表示される

地図では、条件を満たした市町村が緑、満たしていない市町村が赤で表示されます。
サイドバーでは、カバー率を数えるマス目の大きさとソルバーの計算時間を変えられます。

## 問題設定

| 項目 | 内容 |
|---|---|
| 市町村 | 8つ（候補地点は合計 86 か所） |
| センサー | 3種類（広域型・標準型・高精度型）。コスト、有効半径、α値、β値が異なる |
| 条件 | 市町村ごとに「α値の合計」「β値の合計」「カバー率」が必要量以上 |
| 目的 | 置いたセンサーのコストの合計を最小にする |

※ 中央市のカバー率下限は元データでは 100% ですが、ほぼ達成できないため 95% に調整しています。

## QUBO の考え方

変数 `x[i, k]` は「候補地点 i に種類 k のセンサーを置くなら 1、置かないなら 0」です。

- **コスト**：置いたセンサーのコストの合計（小さいほどよい）
- **カバー率の報酬**：市町村を 500 m のマス目に区切り、センサーの円に入るマス目が多いほど得をする項。
  同じマス目を何台も重ねて覆っても得が増えにくい形にしています
- **制約**：「1つの地点には1台まで」「市町村ごとの α・β の合計が必要量以上」を
  `less_equal` / `greater_equal` で表し、重みは Amplify AE の自動調整に任せています

コストとカバー率のどちらを重く見るかは λ_cov（サイドバー下の「詳しい設定」、初期値 4）で調整できます。
初期設定では、8市町村すべてが条件を満たし、総コストはおよそ 6,400〜6,500 になります。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `app.py` | アプリ本体（データ → 変数 → コスト関数 → 制約 → モデル → ソルバー → 結果表示） |
| `helpers.py` | カバー率のマス目づくり、カバー率の報酬の式、地図の描画 |
| `data/data_transformed.json` | 市町村の形、候補地点、センサーの性能のデータ |
| `requirements.txt` | 必要なライブラリ |

## 手元で動かす方法

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`.streamlit/secrets.toml` というファイルを作り、`AMPLIFY_TOKEN = "自分のトークン"` と1行書きます
（このファイルは GitHub には上げません）。そのあと次のコマンドで起動します。

```
streamlit run app.py
```

Render などで公開するときは、環境変数 `AMPLIFY_TOKEN` にトークンを設定すれば動きます。
